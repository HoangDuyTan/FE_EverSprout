# EverSprout - Plant Seeds & Seedlings Store 🌱

EverSprout is a front-end e-commerce website for selling plant seeds and seedlings, developed as a group project for a Front-End course. Built with React.js, the project focuses on creating a modern, user-friendly, and responsive shopping experience inspired by nature.

## Features

- Responsive user interface for desktop, tablet, and mobile devices
- Product catalog for plant seeds and seedlings
- Product search and category filtering
- Product detail pages
- Shopping cart interface
- Nature-inspired design with a clean, modern layout

## Technologies

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap (if used)

## Project Objectives

- Apply React.js to build reusable UI components
- Practice component-based development and state management
- Implement responsive web design
- Improve front-end development and teamwork skills
- Build a foundation for an online plant seed and seedling store

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

   If the project uses Create React App instead of Vite, run:

   ```bash
   npm start
   ```
